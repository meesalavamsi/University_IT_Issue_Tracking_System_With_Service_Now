# Campus360

**Campus360 – University IT Issue Tracking & College Campus Management System**

A ServiceNow scoped application built with the ServiceNow SDK (Fluent / TypeScript). It grows the original University IT Issue Tracking System into a campus management platform. IT issue tracking stays a core module.

| Property | Value |
|---|---|
| Scope | `x_774308_campus360` |
| Package | `campus360` |
| Version | 2.0.0 |
| SDK | `@servicenow/sdk` 4.14.0 |
| Template | `typescript.basic` |

## Modules (planned)

- **IT Issue Tracking (core):** hardware, software, network, campus and hostel Wi-Fi, computers and laptops, lab equipment, building and electrical issues. Covers assignment, technicians, priority and status, tracking and resolution.
- **People:** students, faculty and departments, plus student registration and faculty onboarding.
- **Campus:** hostels, laboratories, infrastructure maintenance and assets.
- **Attendance:** student and faculty attendance.
- **Service requests and notifications.**
- **Reporting:** reports and dashboards.
- **Self-service:** a Student Portal and a Faculty Portal. Administrators use the standard ServiceNow interface.

## Tests

```bash
npm run build && npm test     # local unit + build-configuration tests (Node 22.6+)
```

## Prerequisites

- Node.js 20 or later and npm
- A ServiceNow instance with admin credentials

On Windows PowerShell, use `npx.cmd` and `npm.cmd` if script execution is disabled.

## Setup

```bash
npm install
npx @servicenow/sdk auth --add https://<instance>.service-now.com --type basic --alias dev
```

## Build and deploy

```bash
npm run build    # compile and validate the Fluent sources
npm run deploy   # install the build output on the authenticated instance
```

Always run a successful build before you deploy.

## Project layout

```
now.config.json        App scope and configuration
package.json           Package metadata and npm scripts
src/fluent/            Fluent metadata (*.now.ts): tables, roles, ACLs, rules...
src/fluent/generated/  keys.ts, generated by the build (commit this file)
src/server/            TypeScript server modules used by business rules and other server scripts
```
